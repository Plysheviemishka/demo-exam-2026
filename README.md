# Учусь.РФ — модуль 1

09.02.07 «Информационные системы и программирование», вариант № 5.

## Реализовано в модуле 1

1. Регистрация пользователя с обязательными полями: логин, пароль, ФИО, телефон, e-mail.
2. Серверная валидация логина: латинские буквы и цифры, минимум 6 символов, уникальность в БД.
3. Серверная валидация пароля: минимум 8 символов.
4. Авторизация пользователя по логину и паролю, информативное сообщение при ошибке.
5. Навигация между входом и регистрацией.
6. Личный кабинет пользователя с историей заявок и формой отзыва для завершенного обучения.
7. Страница оформления заявки: выбор курса, дата начала обучения, способ оплаты.
8. Панель администратора с логином `Admin26` и паролем `Demo20`.
9. Просмотр всех заявок администратором и смена статуса: `Новая`, `Идет обучение`, `Обучение завершено`.
10. Защита страниц через сессии и CSRF-токены.

## Реализовано в модуле 2

Проведено улучшение внешнего вида мобильного веб-приложения и подготовка интерфейса под экран смартфона.

1. адаптивный дизайн для мобильного экрана 390×844;
2. улучшенные формы регистрации, авторизации и оформления заявки;
3. подсказки рядом с полями при ошибочном вводе;
4. поле даты заявки в формате `ДД.ММ.ГГГГ` с маской ввода;
5. выпадающие списки для выбора курса и способа оплаты;
6. слайдер в личном кабинете пользователя;
7. 4 одинаковых по размеру SVG-изображения для слайдера;
8. автоматическое переключение слайдера каждые 3 секунды;
9. кнопки переключения слайдера вперед и назад;
10. удобный карточный вывод заявок пользователя;
11. отзыв доступен только после статуса `Обучение завершено`;
12. улучшенная панель администратора;
13. фильтры по статусу, оплате, дате и поисковой строке;
14. сортировка заявок по номеру, пользователю, курсу, дате и статусу;
15. постраничная навигация;
16. модальное окно подтверждения изменения статуса;
17. всплывающие уведомления через flash-сообщения;
18. небольшие микроанимации элементов интерфейса.

## Требования к запуску

- PHP 8.1 или выше.
- MySQL/MariaDB.
- Веб-сервер Apache/Nginx или встроенный сервер PHP.

## Запуск

1. Создать базу данных и таблицы:

```bash
mysql -u root < database/schema.sql
```

2. При необходимости изменить доступ к БД в `config/config.php` или задать переменные окружения:

```bash
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=uchus_rf
DB_USER=root
DB_PASS=
```

3. Запустить приложение из корня проекта:

```bash
php -S localhost:8000 -t public
```

4. Открыть в браузере:

```
http://localhost:8000
```
